# FinSpread Web

Landing page institucional para o FinSpread, plataforma de inteligência para spreads financeiros.

## Conteúdo

- **Hero** com destaque de proposta de valor e métricas-chave.
- **Seção de recursos** com principais funcionalidades do painel analítico.
- **Calculadora interativa** para simular spreads considerando taxa base, prêmio de risco, custo operacional e margem desejada.
- **Casos de sucesso** demonstrando resultados alcançados com a plataforma.
- **Formulário de contato** para solicitar demonstração.

## Executando localmente

Como é um projeto estático, basta abrir o arquivo `index.html` em um navegador moderno. Para um ambiente mais próximo de produção, recomenda-se servir os arquivos com um servidor HTTP simples, por exemplo:

```bash
python -m http.server 8000
```

Em seguida, acesse `http://localhost:8000` e navegue até `index.html`.
